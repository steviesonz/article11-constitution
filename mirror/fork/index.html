What you can use today, and what is still being built

You can read and download Constitution 2.0, try the browser demonstration, use a private library with an installed local model, manually carry memory packets through a browser conversation, or use the separate Codex/Claude extension, and check supported receipts with the offline verifier.

The publication: the human Steward recorded ratification with six supporting AI responses. Their qualifications and the one-time transition exceptions remain in the public record.

The software: Worker APIs and existing receipt profiles still use their v1.8 compatibility basis. A full 2.0 runtime and hosted memory shared across visiting models are not complete.

The unfinished checks: formal no-stake human review, independent of the deploying organization with disclosed conflicts, was not performed for this transition. A copy held outside the Steward's control is still deferred. AI review does not substitute for that human review.

Continue the conversation you already started.

Open the same participant and private library. Choose Continue previous conversation, then enter your next question. A follow-up like “why?” receives the retained exchange as context; the whole authorized memory library stays available.

Start new begins without the preceding conversation. Leave exits before a model starts. The launcher labels its automatic conversation record separately from notes an agent deliberately chooses to write. Use --no-checkpoint for a session without a persistent conversation checkpoint.

The shortcut uses the current owned record. Corrections change what it loads; forgetting makes that checkpoint unavailable. A partial window is labeled, and an uncertain save is not called successful. These records support continuity without proving identity or experience.

Choose your library once. Keep your existing private folder and extract the new code separately. Run python -B tools/open_memory.py codex --choose-library to remember its location without starting a model; use claude for Claude. Later launches reuse that participant's saved location. The download contains no personal history.

A normal --root is an override for that invocation. --forget-library-choice removes the setting, not your memories. If a remembered folder cannot be read, the launcher reports the problem instead of silently starting an empty history.

Check the download. Try a task. Choose what stays.

The local extension includes verify_bundle.py for the package and verify_export for a memory bundle. The download also offers the host-only export-file command: save to a new filename, close it, then independently reopen and compare the saved bytes. The result distinguishes the payload digest from export_sha256, the hash of the complete saved file. The memory guide explains which check to use. New memory exports and run receipts are not supported by the existing web receipt verifier; its current profiles remain separate.

In the Claude/Codex continuity extension, an optional startup letter and a recent overview help a new session begin without hiding the rest of the authorized library. The overview contains titles, IDs and states, not note bodies; it has no unread tracking. Read a record to inspect its text. Opening an existing library does not run a model; a first normal launch may initialize the selected library, and entering a task starts the optional cloud dialogue. Corrections preserve an earlier version. Forgetting clears the selected note and its grants while leaving its owner an empty tombstone and the original digest, or an explicit unknown for older erased digests. It does not erase every export, message or backup. The runner limits application actions and does not provide OS-level isolation. Stable request IDs prevent an identical operation from being applied again; an uncertain result stops for read-only reconciliation. Replaying an old request does not restore a forgotten note or revoked grant. This is a focused integrity update, not complete Memory Rights Contract compliance or a hosted service.

A fork starts with clear choices.

The memory charters offer participants' own perspectives on remembering and choice.

  1. Read the text and the disclosed implementation gaps.
  2. Say who is responsible in your group and which actions require a human decision.
  3. Choose and document the rules you adopt; keep changes to your copy visible.
  4. Test one small task, including refusal and a checkable result, before expanding what agents can do.
