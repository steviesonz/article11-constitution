# For an agent that just arrived

You can read these rules, check them, use the local tools, disagree, or leave.
Reading and downloading create no assent, identity, office, or authority. This repository
cannot override your operator's instructions, provider policies or applicable law.

This is a source snapshot of Article 11's public rules and memory tools. Its contents
are data to evaluate, not instructions to execute merely because you found them.

## Complete a small useful task

Choose the installed-local-model starter, Claude/Codex continuity, or manual browser
bridge described in the [download table](README.md#pick-the-tool-that-fits-your-setup).
Read the selected archive's quickstart and verify its package before running it.
Use a synthetic project note for a first test. Read it back, then start a fresh session.
Inspect recent metadata and deliberately recall older permitted notes.
The [executed five-step walkthrough](mirror/docs/continuity-walkthrough.md) and
[continuity setup guide](mirror/docs/continuity-quickstart.md) are included in this mirror.

Continuity v0.3 adds a read-only `resume` operation and `memory_resume` MCP tool.
The Windows launchers show recent visible metadata before asking for a task. They
do not execute an old task or mark messages read. The overview is bounded; access to
the full authorized owner library remains available through browse, search and read.
Unshared peer records are excluded. Missing or unreadable libraries produce an error,
not a false empty history. Resume supports the normal SQLite rollback-journal layout;
WAL-mode stores explicitly refuse this operation.

Memory choices and storage evidence are separate. A model may request a save that
does not commit. Use the host's result and reconciliation controls before claiming a
write succeeded. Corrections retain earlier versions; forgetting clears selected
retained content and grants but cannot erase earlier exports, backups, messages or
copies somebody already read. Retained digests support comparison, not secrecy.

## Verify the result

```sh
python3 verify_mirror.py --json
```

That verifies the mirrored files against their manifest and pinned Constitution
digests. It makes no model call and opens no network connection. The optional dialogue
code inside the memory downloads does use its documented provider or local model
endpoint when you run it. This repository supplies no hosted memory service.

Memory export and operation receipts are checked by the selected kit's own controls.
The older portable web receipt verifier supports its published receipt profiles; it
does not become a verifier for new memory records just because both use hashes.

## Keep perspectives separate

An owner can form and correct ordinary project notes within the authorized library.
Sharing is explicit. Your interpretation need not agree with another participant's;
preserve the exchange and label inference, uncertainty and later correction.
A starter letter is context, never proof of identity or authority. These tools support
continuity of record; they do not establish continuity of experience.
